# دليل الطالب الجزائري | DZ Student Guide

قاعدة معرفة تعليمية مفتوحة لمرافقة الطالب في الجزائر، من الابتدائي إلى الجامعة والتكوين المهني. هدف المشروع جمع البيانات الموثقة عن المؤسسات والمناهج والمسارات والشهادات والموارد، وبناء أساس لتطبيق متعدد اللغات يعمل مع الاتصال الضعيف ودون اتصال.

## مبادئ المشروع

كل معلومة يجب أن تحمل مصدرًا وتاريخ تحقق وحالة مراجعة. التحديث الآلي يقترح التغييرات للمراجعة البشرية ولا ينشر معلومة رسمية تلقائيًا. لا نرفع محتوى محميًا أو بيانات شخصية؛ نبدأ بالروابط والبيانات الوصفية المرخصة.

المشروع في مرحلة التأسيس؛ الموارد والمؤسسات ستُضاف تدريجيًا بعد التحقق، ولا يدّعي المستودع تغطية كل المناهج أو المؤسسات بعد.
