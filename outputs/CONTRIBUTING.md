# دليل المساهمة

مرحبًا بمساهمات الطلبة والأساتذة والباحثين والمطورين. نهدف إلى معلومات نافعة، حديثة، ويمكن التحقق منها.

## ما الذي يمكنك إضافته؟

- سجل مؤسسة أو مسار أو شهادة أو مادة أو مورد.
- رابط مصدر رسمي أو تعليمي مع وصفه وترخيصه.
- تصحيح معلومة أو ترجمة أو تحسين قالب أو توثيق.
- الإبلاغ عن رابط مكسور أو معلومة قديمة أو انتهاك حقوق.

## قبل الإضافة

1. ابحث عن سجل موجود لتجنب التكرار.
2. فضّل موقع الوزارة أو المؤسسة أو الجهة الناشرة الأصلية.
3. سجل الرابط، تاريخ الاطلاع، اللغة، المنطقة/المستوى، الترخيص إن وجد، وحالة المراجعة.
4. اكتب بوضوح ما هو مؤكد وما يحتاج إلى تحقق.
5. أضف البيانات في الملف المناسب وفق [مخطط البيانات](docs/DATA_MODEL.md).

## مراجعة المساهمات

- السجلات الجديدة تبدأ بالحالة `proposed`.
- لا تُعتمد المعلومة المتغيرة أو الرسمية قبل التحقق من مصدر الجهة المعنية.
- قد تتطلب تغييرات شروط القبول أو المواعيد أو الشهادات مراجعين اثنين.
- التحديث الآلي يُنشئ اقتراحًا فقط؛ المراجع البشري يقرر الاعتماد.
- نحتفظ بتاريخ المراجعة والتغييرات لتسهيل التصحيح والتراجع.

## حقوق النشر

- لا ترفع كتابًا أو درسًا أو بحثًا أو صورة أو فيديو لا تملك حق إعادة نشره.
- يمكن إضافة رابط أو بيانات وصفية موجزة للمحتوى مع ذكر صاحبه وترخيصه.
- لا تستنتج ترخيصًا من كون المحتوى متاحًا مجانًا على الإنترنت.
- احترم طلبات إزالة المحتوى، وأبلغ عن المخالفات عبر Issue أو قناة التواصل المحددة في صفحة المستودع.

## الخصوصية

لا تنشر أسماء الطلبة أو أرقامهم أو نتائجهم أو وثائقهم أو صورهم أو بيانات اتصالهم. لا تضف بيانات اعتماد أو مفاتيح أو رموز وصول أو ملفات إعدادات سرية. ارفع أمثلة اصطناعية فقط.

## جودة الصياغة والبيانات

- استخدم العربية الواضحة، واحتفظ بالأسماء الرسمية كما وردت في المصدر.
- لا تخلط بين الرأي والمعلومة الرسمية.
- لا تصف موردًا بأنه حديث دون تاريخ تحقق.
- اذكر الولاية والبلدية والمستوى بدقة متى توفرت.
- تجنب الوعود بشأن القبول أو التوظيف أو النتائج.

## الإبلاغ عن الأخطاء

استخدم قوالب Issues: بيانات ناقصة، مورد قديم، رابط مكسور، حقوق نشر أو خصوصية، أو اقتراح. أرفق رابط المصدر ولا تضع بيانات شخصية في البلاغ.

## مدونة السلوك

التزم بالاحترام، وناقش الفكرة لا الشخص، وتقبل التصحيح، ولا تضايق المساهمين أو الطلبة. يمكن للمشرفين إخفاء المساهمات الضارة أو المخالفة وشرح السبب.
