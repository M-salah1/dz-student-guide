# دليل الطالب الجزائري | DZ Student Guide

منصة معرفة تعليمية مفتوحة لمرافقة الطالب في الجزائر، من السنة الأولى ابتدائي إلى الجامعة والتكوين المهني. يجمع المشروع بيانات موثقة عن المؤسسات والمسارات والشهادات والمواد والموارد، ويهيئ أساسًا لتطبيق طالب متعدد اللغات يعمل حتى مع اتصال ضعيف أو دون اتصال.

> المشروع في مرحلة التأسيس. هذا المستودع لا يدّعي امتلاك كل الدروس أو تغطية كل المؤسسات بعد. نضيف المعلومات تدريجيًا مع مصدرها وتاريخ التحقق منها وترخيصها.

## الرؤية

بناء مرجع تعليمي جزائري موثوق وقابل للبحث والتحديث والمساهمة المجتمعية، ثم توفير واجهات وأدوات تساعد الطالب على التعلم والتخطيط والتوجيه عبر مساره الدراسي.

## ماذا يشمل؟

- دليل المؤسسات: ابتدائيات، متوسطات، ثانويات، جامعات، كليات، معاهد، مراكز تكوين ومؤسسات ذات صلة.
- المسارات والمراحل والشهادات والامتحانات وشروط الانتقال والتوجيه والالتحاق.
- تصنيف المواد والوحدات والكفاءات حسب المستوى والبرنامج.
- فهرس دروس وملخصات وتمارين ومواضيع امتحانات وبحوث وكتب ومراجع وفيديوهات وقنوات تعليمية ومصادر رسمية، مع روابطها ومصدرها وترخيصها.
- أدوات مستقبلية: خطة تعلم شخصية، اختبارات وبطاقات مراجعة، مقارنة التخصصات، قاموس عربي/فرنسي/أمازيغي، تنبيهات موثقة، تنزيل للعمل دون إنترنت، ولوحات تبين حداثة التغطية والموارد الناقصة.
- مساحة لمساهمات الطلبة والأساتذة والمراجعين، وقوالب منظمة لإضافة البيانات.

انظر [الرؤية والنطاق](docs/VISION.md)، [خارطة الطريق](ROADMAP.md)، [بنية البيانات](docs/DATA_MODEL.md)، [سياسة المصادر والترخيص](docs/SOURCES_AND_LICENSING.md)، و[دليل المساهمة](CONTRIBUTING.md).

## المبدأ الأساسي

كل معلومة قابلة للتتبع: مصدر ورابط وتاريخ تحقق وحالة مراجعة وترخيص عند الحاجة. الاكتشاف الآلي للتغييرات ينشئ اقتراحًا للمراجعة؛ لا ينشر تحديثًا رسميًا تلقائيًا دون تحقق بشري.

## ابدأ بالمساهمة

اقرأ [دليل المساهمة](CONTRIBUTING.md)، ثم استخدم قوالب البيانات في `data/` أو افتح اقتراحًا عبر قوالب Issues. لا ترفع معلومات شخصية للطلبة، ولا تنسخ محتوى محميًا بحقوق النشر دون إذن واضح.

## المستودع والتطبيق

هذا المستودع هو مصدر بيانات وصفية ومخططات وقوالب وتوثيق وروابط مرخصة. يمكن للتطبيق استهلاك البيانات عبر ملفات JSON أو واجهة API مستقبلية. لا تضع أسرارًا أو مفاتيح API أو سجلات طلبة هنا. افصل بيانات التطبيق الشخصية عن هذا المستودع العام.

## اللغات

المحتوى الأساسي حاليًا بالعربية. نرحب بترجمات فرنسية وأمازيغية، مع الاحتفاظ بالمصطلح الأصلي والمراجع الرسمية لتفادي اختلاف المعنى.

المعلومات المتغيرة مثل التسجيلات والمنح والشروط يجب أن تحمل تاريخ التحقق ورابط الجهة الرسمية. المعلومات غير المؤكدة موسومة بوضوح ولا تقدم كحقائق رسمية. لا يقدم المشروع ضمانًا للقبول أو النتائج المهنية.
