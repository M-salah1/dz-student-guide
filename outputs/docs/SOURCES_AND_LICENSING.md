# المصادر والترخيص والتحقق

## ترتيب الثقة المقترح

1. الجهة الحكومية أو الوزارة صاحبة الاختصاص.
2. موقع الجامعة أو المؤسسة أو مركز التكوين نفسه.
3. مكتبة أو ناشر أو منصة تعليمية تملك المحتوى أو تصرح بترخيصه.
4. أستاذ أو باحث معروف يحدد صفته ومصدر مادته.
5. مساهمة مجتمعية قابلة للتحقق، موسومة بوضوح إلى أن تراجع.

ويكيبيديا ويوتيوب والقنوات التعليمية قد تكون نقطة اكتشاف أو مصدرًا إضافيًا، لكنهما لا يحلان محل البرنامج أو الإعلان الرسمي عند وصف شروط رسمية.

## سجل المصدر لكل معلومة

احفظ رابطًا مباشرًا، الجهة الناشرة، نوع المصدر، تاريخ الاطلاع، تاريخ النشر إن ظهر، الترخيص، وما الذي يؤيده المصدر. رابط رئيسي عام غير كاف إذا كان هناك إعلان أو صفحة محددة.

## حقوق النشر

- الرابط العام لا يعني أن المحتوى متاح لإعادة التوزيع.
- لا ترفع كتبًا أو محاضرات أو أبحاثًا أو صورًا أو فيديوهات كاملة من دون ترخيص صريح أو إذن.
- سجّل رابط المورد وعنوانه ووصفًا قصيرًا أصليًا واسم صاحبه وترخيصه.
- إذا سمح الترخيص بإعادة الاستخدام، احتفظ بنص الترخيص والإسناد المطلوب وأي شروط مشاركة بالمثل.
- احذف أو عطّل أي مادة يثبت انتهاكها، واحتفظ بالبيانات الوصفية الضرورية لسجل الطلب دون إعادة نشر الملف.

## التحقق والتحديث

المواعيد، شروط القبول، المنح، البرامج، أسماء المؤسسات وروابطها قابلة للتغير. سجّل `last_verified_at`، وضع السجلات القديمة في مراجعة. الرصد الآلي يقارن المصادر ويقترح تغييرًا؛ لا يعدّل معلومة رسمية مباشرة.

## تنوع المصادر

اجمع مواد قديمة وحديثة مع سنة الإصدار والنسخة حتى لا يختلط البرنامج القديم بالجديد. أظهر تاريخ المصدر بوضوح، ولا تحذف المرجع التاريخي إن كانت له قيمة تعليمية.
