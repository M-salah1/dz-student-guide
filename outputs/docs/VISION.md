# الرؤية والنطاق

## الغاية

مرافقة الطالب في الجزائر منذ السنة الأولى ابتدائي وحتى التعليم العالي والتكوين المهني، بتجميع المعرفة التعليمية الموثقة وتقديمها بشكل منظم وسهل الاستخدام.

## الجمهور

- الطلبة وأولياء الأمور.
- الأساتذة والموجهون والباحثون.
- المؤسسات التعليمية والجمعيات والمساهمون.

## مكونات المنظومة

1. **قاعدة معرفة:** المؤسسات، المراحل، المسارات، الشهادات، المناهج والمواد.
2. **فهرس موارد:** دروس، تمارين، امتحانات، بحوث، كتب، فيديوهات، قنوات ومصادر رسمية؛ مع روابط وبيانات ترخيص.
3. **تطبيق الطالب:** بحث، خطة تعلم، مراجعة واختبارات، توجيه، قاموس، تنزيل دون اتصال، وتنبيهات موثقة.
4. **مجتمع مساهمين:** طلبة وأساتذة ومراجعون، قوالب وطلبات تحسين وسجل تغييرات.
5. **نظام تحديث:** رصد تغييرات المصادر، فتح اقتراحات، مراجعة بشرية، ثم نشر إصدار بيانات.

## مبادئ التصميم

- الثقة قبل الاتساع: كل سجل له مصدر وحالة وتاريخ تحقق.
- الشمول: جميع الولايات والمراحل والمسارات، مع توسع تدريجي واقعي.
- الانفتاح: تنسيقات قابلة للقراءة آليًا وواجهة API مستقبلية.
- احترام الحقوق: روابط وبيانات وصفية أولًا؛ إعادة النشر فقط بترخيص يسمح.
- الخصوصية: لا يحتاج فهرس المعرفة إلى ملف الطالب الشخصي.
- تعدد اللغات: العربية والفرنسية والأمازيغية، مع ربط المصطلحات وعدم فقد المعنى.
- إتاحة الوصول: تصميم للهاتف، اتصال ضعيف، قارئات الشاشة والعمل دون إنترنت.
- الشفافية: توضيح مصدر البيانات وحدودها وموعد آخر مراجعة.

## حدود المشروع

المستودع لا يضمن اكتمال كل المصادر أو صحة البيانات التي لم تُراجع. لا يمثل الجهات الرسمية ولا يقدم قرارات قبول أو معادلة أو توجيه ملزمة. المعلومات المتغيرة يجب الرجوع فيها إلى الإعلان الرسمي الأحدث.

## تصور لاحق للتطبيق

- تطبيق ويب/هاتف يستهلك إصدارات بيانات عامة.
- مزامنة اختيارية، ومعلومات التقدم محليًا أو ضمن حساب بموافقة المستخدم.
- لا تُرفع بيانات الطالب إلى المستودع العام.
- توصيات الدراسة قابلة للتفسير، والطالب يستطيع تعديلها أو إيقافها.
- مصادر البحث تكون ظاهرة بجانب كل نتيجة.
