# الخصوصية والأمان

المستودع عام؛ كل ما يُرفع إليه يمكن نسخه والاحتفاظ به. لا تضع فيه بيانات طالب أو أستاذ شخصية، نتائج، وثائق، عناوين خاصة، صورًا غير مصرح بها، مفاتيح، كلمات مرور، رموز وصول، ملفات إعدادات سرية أو سجلات استخدام قابلة للتعرف على الأشخاص.

## تصميم التطبيق مستقبلًا

- اجعل الاستخدام الأساسي ممكنًا دون حساب.
- خزّن التقدم محليًا افتراضيًا؛ الحساب والمزامنة خياران منفصلان بموافقة واضحة.
- اجمع أقل قدر ممكن من البيانات، وحدد مدة الاحتفاظ والحذف.
- لا تجعل التوصيات أو الإحصاءات تكشف فردًا أو مجموعة صغيرة.
- افصل بنية بيانات التطبيق الخاصة عن بيانات المعرفة العامة في GitHub.
- استخدم متغيرات بيئة أو مخزن أسرار للخدمات؛ لا تضع مفاتيح API في المستودع أو تطبيق العميل.
- وفر طريقة لطلب حذف الحساب والبيانات عند بناء الحسابات.

## عند وقوع تسريب

احذف السر من الخدمة فورًا ودوّره/ألغِه؛ حذف الملف في commit لاحق لا يمحو النسخ السابقة. أبلغ مشرفي المستودع دون نسخ السر إلى Issue عامة.
