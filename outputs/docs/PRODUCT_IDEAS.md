# أفكار المنتج

قائمة أفكار للنقاش وليست وعدًا بأن كل ميزة ستنفذ. اختبر كل ميزة مع الطلبة والأساتذة.

## للطالب

- ملف مسار تعليمي اختياري يوضح المرحلة الحالية والخيارات التالية.
- تقويم مراجعة مرن حسب تاريخ الامتحان والوقت المتاح.
- دروس قصيرة وأسئلة استرجاع وبطاقات مراجعة وامتحانات تجريبية مع شرح.
- لوحة تقدم خاصة بالطالب، تعمل محليًا وتبقى قابلة للتصدير والحذف.
- توصية بموارد بديلة إذا كان الرابط مكسورًا أو الاتصال بطيئًا.
- أداة مقارنة تخصصات تعرض شروط الالتحاق والمواد والآفاق ومصادر كل بند.
- تنبيهات مواعيد رسمية بعد التحقق، وإظهار تاريخ انتهاء كل إعلان.

## للأساتذة والمساهمين

- قوالب موحدة لإضافة درس أو امتحان أو خطة أو بنك أسئلة.
- محرر اختبارات مع مفتاح الإجابة وشرح ومستوى الصعوبة.
- صفحة فجوات التغطية حسب الولاية والمرحلة والمادة.
- فرق مراجعة حسب الولاية والتخصص، مع إظهار جودة المراجعة لا عدد المساهمات فقط.
- سجل تغييرات ومقترحات تحديث، وسهولة الاعتراض والتصحيح.

## للجميع

- بحث عربي وفرنسي وأمازيغي مع مرادفات ومصطلحات علمية.
- وضع خفيف واتصال ضعيف، تنزيل موارد مرخصة، وإتاحة لقارئ الشاشة.
- تغطية التكوين المهني والتعليم العالي إلى جانب التعليم العام.
- إحصاءات مجمعة عن الموارد المطلوبة والناقصة من دون تعقب الأفراد.
- واجهة API وإصدارات بيانات ثابتة ليسهل بناء تطبيقات ومبادرات أخرى.
