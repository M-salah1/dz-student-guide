# خارطة الطريق

هذه خارطة أولية قابلة للتعديل. كل مرحلة تسبقها مراجعة جودة ومصادر.

## المرحلة 0 — تأسيس المجتمع والحوكمة

- [x] توثيق الفكرة والنطاق والمبادئ.
- [x] وضع سياسة المصادر والترخيص والخصوصية والمراجعة.
- [x] إنشاء مخططات وقوالب البيانات ودليل المساهمة.
- [ ] تعيين اسم وشعار وهوية بصرية بمشاركة المجتمع.
- [ ] تحديد فريق مراجعة أولي ومتطوعين حسب الولاية والتخصص.

## المرحلة 1 — نموذج بيانات صغير موثوق

- [ ] تثبيت قوائم الولايات والبلديات والمراحل واللغات والمجالات.
- [ ] إضافة أمثلة بيانات تجريبية غير مضللة أو سجلات فعلية موثقة.
- [ ] وضع آلية تدقيق آلي للحقول والروابط والتراخيص.
- [ ] نشر قائمة المصادر الرسمية المعتمدة لكل قطاع.

## المرحلة 2 — نقطة انطلاق تعليمية

- [ ] اختيار نطاق تجريبي مع المجتمع: بكالوريا، جامعة/تخصص، أو ولاية ومؤسساتها.
- [ ] جمع المؤسسات والمسارات والمواد والموارد ضمن النطاق المختار.
- [ ] مراجعة بشرية مزدوجة للبيانات الحساسة أو المتغيرة.
- [ ] قياس الاكتمال والحداثة والموارد المفقودة.

## المرحلة 3 — تجربة تطبيق الطالب

- [ ] بحث وتصفية حسب الولاية والمرحلة والمادة واللغة.
- [ ] صفحة مورد واضحة بالمصدر والترخيص وتاريخ المراجعة.
- [ ] خطط دراسة واختبارات قصيرة وبطاقات تذكّر.
- [ ] حفظ التقدم محليًا أولًا؛ حسابات اختيارية لاحقًا.
- [ ] دعم الواجهة العربية والفرنسية، ثم الأمازيغية.

## المرحلة 4 — التغطية والتحديث

- [ ] إضافة بقية المراحل والولايات والمؤسسات تدريجيًا.
- [ ] مراقبة تغيّر الصفحات الرسمية وإنشاء اقتراحات تحديث للمراجعين.
- [ ] تنبيهات للتسجيلات والمنح والمسابقات بعد التحقق من الجهة الرسمية.
- [ ] تنزيل موارد مرخصة للاستخدام دون اتصال.
- [ ] إحصاءات مجمعة لتحديد فجوات التغطية دون تتبع شخصي للطلبة.

## المرحلة 5 — منظومة تعليمية مفتوحة

- [ ] لوحة للأستاذ لإنشاء موارد واختبارات ومراجعتها.
- [ ] قاموس مصطلحات عربي/فرنسي/أمازيغي.
- [ ] واجهة API موثقة وإصدارات بيانات مستقرة.
- [ ] تكاملات اختيارية مع منصات ومكتبات ومصادر تعليمية مرخصة.
- [ ] تقييم الوصولية والأداء على الهواتف والاتصال الضعيف.

## معايير الانتقال بين المراحل

وجود مصدر موثوق، ترخيص واضح، نسبة أخطاء منخفضة، مراجعين نشطين، وإمكانية تصحيح البيانات أو سحبها. لا يعني اتساع التغطية جودة أعلى إن غابت هذه الشروط.
