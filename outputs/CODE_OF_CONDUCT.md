# مدونة السلوك

نريد مساحة آمنة ومرحبة للطلبة والأساتذة والمساهمين من مختلف الولايات واللغات والخلفيات.

## السلوك المتوقع

- الاحترام والإنصات والنقد البنّاء.
- تقديم مصادر عند تصحيح المعلومات.
- مساعدة المبتدئين دون سخرية أو تمييز.
- الاعتراف بأصحاب المحتوى والجهد.
- الإبلاغ عن المضايقات أو انتهاكات الخصوصية وحقوق النشر.

## سلوك غير مقبول

التحرش أو التهديد أو التمييز أو الإهانة، نشر بيانات شخصية، السبام، سرقة المحتوى، أو تعطيل مساهمات الآخرين عمدًا.

يمكن للمشرفين تعديل أو إخفاء المحتوى المخالف، أو تقييد المشاركة عند الضرورة. أبلغ فريق المشروع عبر قناة التواصل المنشورة في صفحة GitHub.
